This PR scaffolds the Flyt app with branding, mocks, and tests.

What’s included:
- Branding: "Flyt" name and logo in header
- MSW mocks: flights search, offers recheck, bookings (create/get), payments (intent/confirm), itineraries (list/detail), admin (bookings list/detail/refund)
- Typed Lite API client under src/lib/api/client.ts with auth/refresh, retry/backoff
- Unit/component tests (Vitest + Testing Library)
- Playwright E2E tests: happy path (search → offer → checkout → confirm), admin refund, basic a11y checks
- Playwright webServer config to build/start app automatically
- Providers wired with MSW in all envs for tests
- README with setup, env vars, and testing instructions

Local verification (all green):
- pnpm typecheck
- pnpm lint
- pnpm test
- pnpm e2e

Notes:
- App uses MSW mocks only; real Lite API can be wired later by setting NEXT_PUBLIC_LITE_API_BASE_URL and adding credentials.
- BASE_URL default/path fix ensures relative requests work in built app so MSW intercepts during E2E.
